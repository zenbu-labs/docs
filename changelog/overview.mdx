<Update label="May 15, 2026">

## What's new

### `/Applications` support in `create-zenbu-app`

`create-zenbu-app` now scaffolds projects ready to run from `/Applications`, so you can build and ship desktop-style apps without extra setup. Try it with `npx create-zenbu-app my-app` — see the [Quickstart](/quickstart) for the full flow.

## Updates

### Smoother `create-zenbu-app` experience

Generated apps come with refreshed templates and project structure, getting you to a running app faster. See [Quickstart](/quickstart) for the latest walkthrough.

## Fixes

### Hot reload picks up new services

Adding a new service file no longer requires restarting the dev server — hot reload now detects it automatically. Learn more in [Services](/core/services).

### No more crashes when deleting service files

Removing a service file used to crash the dev server. It now cleans up gracefully and keeps your session running.
